User guide

How to use every tool in the editor

Digital Forge is a video editor and an image studio that run entirely on your own PC. The editing itself needs no AI at all. The generation, editing, masking, tracking and sound tools run as local model jobs on one 16 GB NVIDIA card, and everything they make goes back into the same project.

This guide follows the app: one chapter per workspace, then the models, step-by-step recipes and reference tables. Hover over or tap a region of the window map to see what it is, and click it to jump there.

The editor works without any AI installed

Import, cut, trim, transitions, titles, captions from subtitle files, audio mixing and export all run on FFmpeg and the built-in compositor. Install the AI features you want later by running Install-Digital-Forge.bat again.

Projects and where files go

A project is one .aivproj file. Use File → Save (Ctrl+S), Save as… and Open project… (Ctrl+O). The file stores the timeline, every clip setting, Photo Edit documents, mask and VFX layers, the Ref2V cast and its take ledger. It stores references to media, not the media itself, so keep your source files where they are.

FolderWhat lands there
projects\<id>\media\Stills made in Image Studio and Photo Edit, rendered VFX, generated sound effects.
elements\Wan Alpha elements, imported PNG sequences and inserted characters, each in its own folder.
exports\spritesheets\Spritesheet atlases with their Godot .tres and JSON files.
cache\Thumbnails, waveforms, mattes, depth. Safe to delete; it is rebuilt when needed.
.aiv\Logs: launcher.log, worker.log (every model job), install-*.log.
Wherever you chooseGenerated video (LTX, H3, clip edits, SAM 2 mattes) and exports ask for a save location first.

Nothing is uploaded. Every model runs on your machine, and generated files carry their recipe (prompt, seed, model, settings) in the project so you can see how something was made.

Ready states and memory

Every AI feature checks its own model and runtime and says what is missing instead of failing later. You will see this in three places:

  • Pills on a panel: READY or MISSING in Image Studio, Pack ready, Pack missing, Dependencies missing in the clip editor. Each one names the fix.
  • The runtime line at the bottom of the AI panel: Python, LTX, checkpoint, Gemma, Foley LoRA, MOSS SFX, Kiwi-Edit, Whisper, MiniMax-H3, H3 Draft, H3 Turbo and Ref2VA, each ✓ or ×.
  • Disabled buttons: hover them. The tooltip says what they need (a selected clip, a second image, a model).

The resource guard

Only one GPU model job runs at a time. Before a big job starts, the app checks free Windows commit memory and VRAM against what that job is known to need. If something else is holding memory (a local LLM, a game, a browser with many tabs), a dialog shows Commit and VRAM needed and available, lists the processes holding them, and offers Cancel, Release this app's worker (stops a resident LTX worker this app started, nothing else) and Continue anyway.

Continue anyway can crash rather than fail cleanly

When Windows runs out of commit memory the model worker usually dies with 0xC0000005 instead of a readable out-of-memory message. Close the other program first when you can.

Start here

Your first edit, in ten minutes

  1. Start the app with Launch-AIV-Studio.vbs. It opens on an empty project with a 1920 × 1080, 24 fps sequence.
  2. In the Media bin, click Import media and pick a few clips, stills or audio files.
  3. Drag a clip onto V1 · Primary, or double-click it to append it to the end.
  4. Press Space to play. Drag the ruler to scrub; you hear the audio as you drag.
  5. Park the playhead and press S to split the selected clip, or use the blade tool (B).
  6. Select a clip and open the Transitions section of the Inspector. Pick Cross Dissolve as its Transition in.
  7. In the Media bin's Graphics tab, add a Lower third and type your text in the Inspector.
  8. Click Quick preview above the timeline to render six seconds around the playhead with the real mix.
  9. Open the Export tab, keep MP4 with NVENC, and click Choose file and render.
  10. Save the project with Ctrl+S.

Media bin

The left panel has three tabs and a search box that filters whichever tab is open.

Media

Import media accepts MP4, MOV, MKV, WebM, AVI, M4V, MP3, WAV, FLAC, M4A, AAC, PNG, JPG and WebP. Each file is probed with FFprobe, so the tile shows its size, frame rate, length and a real thumbnail. Tiles with an AI badge were generated in this project.

  • Drag a tile onto a lane. Picture goes on video lanes, sound on audio lanes; other lanes refuse the drop.
  • Double-click or + Timeline appends it to the end of V1, or of A1 for a sound file.
  • Right-click for Preview, Rename…, Add to end of timeline and Remove from project. Removing takes it out of the project, not off your disk.
  • Select a tile while nothing on the timeline is selected, and the monitor previews that source on its own.

Effects

Twelve looks you can apply to the selected V1 clip with one click. They set the same sliders as the Inspector's Effects section, so you can fine-tune them afterwards. See the full list.

Graphics

Title templates (Centered title, Lower third, News banner, Corner bug) land on G1 · Graphics and Caption lands on C1 · Captions, five seconds long, at the playhead. Import SRT / WebVTT turns a subtitle file into caption clips. See Titles and captions.

Program monitor

The monitor draws every frame with the compositor, the same renderer the export uses: fitting and cropping, transitions, overlays, titles, clip effects, background removal and mask VFX layers. What you see is what the file will contain. The header shows which engine drew the frame and how long it took.

A new project has seven tracks, top to bottom: G1 · Graphics (titles), V2 · Overlay (pictures and cutouts over the picture), V1 · Primary (the picture), A1 · Clip Audio, A2 · SFX, A3 · Music and C1 · Captions. Time is stored as exact fractions, so frame positions never drift.

Previews

  • Full preview renders the same window with your master export settings, upscale included.
  • Both open in a dialog with Render again at playhead.

Right-click menus

On a clip: Play from clip, Open AI clip editor…, Save trimmed clip to project media… (writes just the trimmed range as a new MP4 or WAV, handy as a Ref2V reference), Split at playhead, Duplicate, Disable clip, Clear transitions, Ripple delete and Delete.

Clips show a filmstrip and waveform. Gold ramps on a clip's edges are its transitions; a VFX badge means it carries mask VFX layers.

From the Sequence menu or the status bar. Set the name, width and height, frame rate (23.976 to 60 fps), audio sample rate, and the default fit for clips used by every clip that has no override. Video Editor

Background removal on the timeline

Any video or image clip can have its background removed. The cut becomes the clip's transparency in the monitor and the export, so whatever is under the clip shows through: put the subject clip on V2 and a new background on V1. On V1 alone the cutout sits over black.

MethodBest for
Auto (BiRefNet) GPU jobOne obvious subject. Finds the foreground in every frame with soft, detailed edges. No clicks needed. Up to 5,400 frames.
Pick subject (SAM 2) GPU jobChoosing exactly which subject. Click it in the monitor; SAM 2 follows it through the clip with hard edges. Up to 900 frames.
Pick + soft edges (both) GPU jobThe best cutout. SAM 2 chooses the subject and BiRefNet gives it soft hair and motion-blur edges. The slowest.
  1. Select the clip and choose a Method in the Inspector's Background removal section.
  2. For the SAM 2 methods, click Pick subject in monitor, then click the subject. Shift+click marks something to remove. You can move the playhead and add points on other frames where SAM 2 needs help.
  3. Optionally turn on Track assist (CoTracker3): it follows your points and re-prompts SAM 2 every 12 frames, which keeps it on a subject that turns or is briefly covered.
  4. Click Remove background. The matte is cached, so remaking with the same settings is instant.
  5. Adjust live, without remaking: Edge feather, Grow / shrink (negative eats into a halo), Invert (remove the subject) and Show cutout.

The section's badge reads REMAKE when you have changed the method, points, track assist or edge smoothing since the matte was made, or trimmed the clip past it.

Video Editor

Transitions

Every clip has two transition slots: Transition in and Transition out. Each has a search box over all 58 transitions, a grouped list and a duration.

  • At a cut, the two sides fuse: the incoming clip's choice sets the look, and the longer of the two durations wins, so nothing is cut short.
  • On the first clip, the in transition fades up from black (white or grey for dip transitions); on the last clip, the out transition fades down.
  • The Head cut and Tail cut lines show what will actually happen at each end.
  • Apply to all cuts copies this transition to every cut on V1. Clear removes both.
  • Audio crossfades with the picture.

A transition needs frames beyond the visible edit. If a clip has no spare frames, the edit closes up by the transition's length, and the timeline draws it where it will really land. The transition catalogue lists all 58 with descriptions.

Video Editor

Titles and captions

Titles and captions are editable clips, never burned into the picture. Add them from the Media bin's Graphics tab, from Text Motion in the clip editor, from a subtitle file, or with Auto-caption this clip.

Select one and the Inspector shows: Template, Text, Subtitle, Duration, Font size, Backdrop (Transparent, Filled box, Outline frame, Underline), Font (Display, Clean sans, Cinema serif, Tech mono), Weight, Text outline, Shadow, Backdrop opacity, the four motion controls (Animate in, Animate out, While visible, Easing) with Animation time, the colours, and opacity.

All the motion names are in the text motion catalogue.

The AI panel

The Inspector's AI tab holds three sections. It stays loaded while you look at other tabs, so a running generation keeps its settings and timer.

  • Clip editor: a shortcut to the AI clip editor.
  • SAM 2 subject tracking: make a standalone matte video (below).
  • Clip generation: LTX 2.3 or MiniMax-H3, chosen with Model. The fields change with the model, because the two have different frame and size rules.

SAM 2 subject tracking

Makes a new video from a subject in the selected V1 clip, over its trimmed range. GPU job

  1. Select the clip and click Add points from monitor.
  2. Click the subject in the monitor; Shift+click to exclude a region.
  3. Choose Output: Matte (black-and-white mask for keying), Cutout (subject on black) or Removed (subject blacked out, for clean-plate work). Add a little Feather to hide jagged edges.
  4. Click Track subject + add to bin, and choose where to save. The result appears in the Media bin.
Which masking tool?

To cut a subject out in place on the timeline, use Background removal. For a separate matte file to use elsewhere, use this panel. For effects on the subject, use Mask Effects. For a mask inside a composite, use Masks in VFX or Photo Edit.

Generate with MiniMax-H3

MiniMax-H3 generates picture and sound in one denoising loop, so the soundtrack is locked to the action. The result lands as two linked clips: video on V1 and its 32 kHz stereo audio on A1, so you can mute or replace the sound without touching the picture. H3 is guidance-distilled: there is no CFG and no negative prompt. GPU job

References → video + audio (Ref2VA)From a tray of image, video and audio references. The full version of this is the Ref2V workspace.

Kiwi-Edit

Kiwi-Edit 5B changes an existing range from an instruction: “Remove the microphone”, “Make it snow”, “Change the jacket to red”. GPU job

ControlMeaning and advice
ModeInstruction only, or Reference image guided with Choose reference image… (for example, the jacket you want).
Edit lengthStable: one 81-frame pass, the supported quality mode. Long: overlapping 81-frame passes, each conditioned on the one before, joined at the least disruptive seam. The readout shows the number of passes and the output length.
Instruction strengthHow hard the instruction is pushed (1–10). At 1.0 it barely steers and the result looks like the input; 4 is a good start. Above 1 costs a second pass per step.
AvoidWhat the edited range should not contain.
Steps4–60, default 24. More is cleaner with diminishing returns past about 30.

AI clip editor · Visual Edit

LTX Retake

Regenerates just the selected range, keeping the frames around it, from a prompt. GPU job

  • Regenerate: Video + audio, Video only (keeps the original sound) or Audio only (keeps the original picture). The kept half is rebuilt straight from your source, not from the model.
  • Guidance: Fast (one pass per step, the documented mode) or Experimental guided-distilled (four passes per step, adds Prompt strength; diagnostic). Avoid only works in the guided mode.
  • Enhance prompt uses LTX's built-in Gemma prompt enhancer: good for short prompts, leave it off when your prompt is already precise.
  • Write prompts as: subject and appearance, the action in order, camera, lighting and style, then the sound and its timing.
  • Keep the range at least 2 seconds. Shorter ranges run, but the untouched frames around them dominate and the original tends to come back.

The panel shows the exact frame range it will regenerate, and refuses sources outside the 16 GB profile before starting. After the run, Context + seams shows one second either side so you can judge the joins; Generated range shows only the new part.

AI clip editor · Visual Edit

Mask Effects

Mask Effects tracks one subject with SAM 2 and applies a look to it that follows it through the range: a glow behind a dancer, lightning around a hand, the background blurred, a face pixelated. The look is saved as a VFX layer on the clip and rendered live by the monitor and the export, so you can change it later.

  1. Set the range (up to 900 frames). Choose + Include and click the subject in the preview; − Exclude for anything that should not be part of it.
  2. Click 1 · Track subject GPU job. The matte is tracked once and cached; every look afterwards reuses it.
  3. Pick a complete recipe (Anime Power Up, Dark Magic Aura, Energy Shield, Comic Surge, Cinematic Explosion Plate) or an effect algorithm, and adjust. Live look and Play range preview it.
  4. Click 2 · Save VFX layer (renders live), then Done · keep VFX layer. The clip gets a VFX badge.
  5. Optional: Insert baked copy or Replace range (bake) render the look to a video file.

AI clip editor · Visual Edit

VFX: the clip compositor

The VFX mode opens a full layered compositor over the clip. The clip is the plate, the bottom layer. You add elements, pictures, text and shapes over it, track points to attach them, and then Render VFX to put the result back on the timeline. It is the same engine as Photo Edit, with time added, so every layer has the same stack and masks.

Getting around

  • The time bar above the picture has first frame, play, a scrubber, the timecode and the composition length. Proxy scrubs from lighter proxies; rendering always uses full frames.
  • The right column holds Render, Spritesheet, Pictures (add any still as a layer) and Other video (add stock footage as a layer at the current frame).
  • Whole clip or the range button sets how much of the clip the plate covers.

Elements and Wan Alpha

Elements are transparent animated effects: smoke, fire, sparks, energy. Open the Elements card from Elements on the Canvas card.

  • Click an element to add it as a layer at the current frame; the wand icon adds it as an emitter that spawns copies over time.
  • Import PNG folder… brings in any RGBA PNG sequence.
  • Generate with Wan Alpha GPU job: pick a preset (smoke wisp, fireball, magic sparks, flames, explosion, dust burst, energy aura, flame aura, energy rings, radial burst, held fireball orb), edit the prompt and name, choose 33 frames (about 1.5 min) or 81 frames (about 4 min), and Generate element. Output is 832 × 480 at 16 fps. Close a local LLM first.
  • A media layer's Timing card sets its source fps, start frame, in and out points, loop and loop crossfade. Save loop to element makes it the element's default.
  • Wan Alpha elements are mostly translucent. An Alpha curve step thickens a fireball's core; Unmultiply turns footage shot on black into a glow with transparency.

Tracks: attach things to motion

The Tracks card appears once the plate is video.

  1. Choose the Engine: Built-in (Lucas-Kanade), no model needed; or CoTracker3 GPU job, which is far more robust (installed by the Motion feature; non-commercial licence).
  2. Select the layer to attach (an element, a picture, text), then click Track a point + attach the selected layer and click the point on the picture, such as a hand.
  3. The layer now follows. Lag delays it by up to 24 frames; Anchor at frame re-measures from the current frame; Detach stops it.
  4. Or track the centre of a SAM 2 matte from From a SAM 2 matte, which holds on a whole subject rather than a point.

Trail (in the stack): the layer's base follows a track and its top follows where the track was up to 48 frames earlier, so smoke bends behind a moving hand. Emitters: spawn at a track or a fixed point, with rate, lifetime, velocity, spread, scale and opacity from birth to death, spin and seed; every frame is repeatable.

Depth occlusion

Compute depth GPU job measures the plate with Video Depth Anything once (cached). Then Occlude by depth hides the selected layer wherever the plate is nearer the camera, so an effect can pass behind a foreground object. Adjust the depth plane and softness in its mask entry.

Render

Render VFX composes every frame at full size and encodes an H.264 MP4 with the clip's own sound for the same span. Then choose Replace a–b s on the timeline (the clip keeps its head and tail) or Insert after the clip. The original footage is never changed and the render is saved in Project Media.

AI clip editor · VFX

Insert character (Wan Animate 2)

Replace a person in a shot with a character from a picture. Wan Animate 2 animates your character with the actor's exact motion on a plain background; SAM 2 and BiRefNet cut it out; it is placed over the actor, aligned frame for frame. Then a clean plate paints the actor out around it.

  1. Open the clip in VFX and set the plate to the part you want (up to 900 frames).
  2. In Masks, click New mask, use Click-select to put three or so points on the actor, then Run GPU job. SAM 2 tracks the actor through the range.
  3. Optional: Tracks → Compute depth.
  4. In Insert character: give it a Name, pick the Character picture (a full-body shot on a plain background works best), describe it, keep Driving clip on This plate, and set Actor matte (SAM 2) to the mask you made.
  5. Choose Steps (10 is the default), Seed and Size (384² fast, 512² the 16 GB preset, 640² slow). Tick Add a Relight step to match the plate and Paint the actor out around the character.
  6. Click Animate and insert GPU job. On the reference machine, 75 frames at 512² took about 10 minutes.
  7. Scrub to check, then Render VFX and Replace.
What the clean plate needs
  • A locked-off camera. It rebuilds the background from frames around the shot and refuses a moving camera with “not locked off”.
  • It is one still for the whole range, which is right for a few seconds. Over a long range, lighting drift may show.
  • The gaps it cannot see are filled with LaMa when the Photo Edit models are installed.

Character layers are kept in the element library, so you can place them again from the card. Paint the actor out runs the clean plate on its own for a character you already placed. The character's scale follows the actor's height and its feet land on the actor's feet line.

Image Studio

Edit with Qwen Image Edit 2511

Edit mode changes a picture from an instruction and can combine up to three images, for example to put the person from one picture into the scene of another. GPU job

  1. Select the image on the canvas. It is Image 1.
  2. Optionally click the Image 2 and Image 3 boxes to add more pictures. Refer to them in the instruction as picture 2 and picture 3.
  3. Write the Edit instruction: say what changes and what stays. Rewrite GPU job has Qwen2.5-VL look at the pictures and rewrite your instruction the way Qwen's own enhancer does; Undo restores yours. It needs the Z-Image trainer runtime installed.
  4. Pick a preset: Lightning (4 steps, the fast default), Balanced (8 steps) or Quality (40 steps with True CFG 4 and a negative prompt).
  5. Output size: Default keeps Image 1's shape at about one megapixel, which is what Qwen was trained on. A different shape reframes the picture. Above about 1.6 MP it gets slower and drifts more.
  6. Click Generate edited image. The result is added as a new layer; the original is untouched.
Start and end frames for a video

Generate one frame, then edit it into the end state (“the same knight, now with the sword raised, same background and lighting”). Two frames that share composition and lighting give H3 and LTX a smooth path between them. See the full recipe.

Image Studio

Train a Z-Image LoRA

Teach Z-Image a character, a person, a style, a product or an outfit from your own pictures, then use it in Generate. Captioning and training are separate GPU jobs. GPU job

  1. Train for: Turbo (for Fast mode, with a training adapter) or Base (for Creative mode).
  2. Give it a LoRA name and a Profile: designed character, person identity, visual style, product or object, clothing or concept.
  3. Keep the suggested rare Trigger token; ordinary words and names keep their old meaning and overpower the training. Set the Class noun (for example man, robot, jacket).
  4. Choose images, then Auto-caption with the Qwen 2511 encoder or Gemma 3 for more detail.
  5. Review every caption in Dataset review. Fix them, and remove pictures with quality flags. Training will not start until they pass validation.
  6. Pick the preset: Resolution 512 (fastest), 768 (balanced for 16 GB) or 1024 (recommended for identity), and steps, rank, alpha, learning rate, checkpoint interval and how many to keep.
  7. Click Train Z-Image-Turbo LoRA (or Train Z-Image Base LoRA). Save & pause frees the GPU; a paused job resumes exactly where it stopped with Resume to N total steps.
  8. Under Saved checkpoints, Test in Image Studio loads a checkpoint in the right mode with its trigger already in the prompt.

Continue from LoRA folder starts a new training phase from an existing adapter's weights, with a fresh optimizer. To continue the same run exactly, pause and resume instead.

Photo Edit

How Photo Edit works

Photo Edit is a layered, non-destructive photo editor. Open it from the workspace switcher and pick an image on the right, or from Edit on any Image Studio tile. Every change is a step you can reopen, reorder or switch off, the original file is never changed, and the whole document is saved in the project.

  • A document has layers (pictures, text, shapes, paths, gradients, Matrix rain).
  • Each layer has its own stack of steps (grade, relight, retouch…) and its own masks.
  • The whole picture has geometry (rotate, flip, straighten, crop).

Ref2V

Ref2V: direct a shot from references

Ref2V turns a cast of references (pictures of your characters, a clip for the motion, a voice, a room tone) and a written shot description into a video with sound, using MiniMax-H3 Ref2VA. Every run is kept as a take you can restore. GPU job

1. Build the cast

  • Add media from the project: up to 9 images, 3 videos, 3 audio clips, 12 in all. Video and audio must each be 2–15 seconds, and no more than 15 seconds per kind in total. Use Save trimmed clip to project media… on the timeline to cut a reference to length.
  • Each reference shows the label the model will see: <Picture 1>, <Video 1>, <Audio 1>. Order matters: reordering renumbers them. A video with its sound on takes an audio slot before its video slot.
  • Tick the roles that apply: subject or identity, visual style, motion or action, camera or composition, frame anchor (the shot starts from this picture), continue clip, voice or timbre, ambience or sound, music.
  • For each role pick a strength: Keep exactly, Adapt or Inspired by.
  • A video's soundtrack can be switched off, or split into its own audio reference.
  • + define subject names something visible in a picture (<Subject 1>) so the description can refer to it. apply onto transfers a reference's quality onto another subject instead of showing it.

2. Set the output

  • Duration: 124 to 345 frames (about 5 to 14 seconds). Aspect and Resolution Tier: native 768p, 544p for 16 GB, 480p, 416p, or custom. The tokens-per-frame badge turns from safe to heavy as the canvas grows.
  • Sampling: Base with 20, 30 or 50 steps (quality), or LightX2V Turbo v0.1 at 4 steps (fast drafts). Motion Shift 12 is the published value.
  • Reference Image Detail: Match canvas is the default; 1024 or 2048 px hold identity better and cost time on every step. Reference Video Detail: 384 px is safe on 16 GB.
  • VAE Tile Size 256 is the released setting. Memory: balanced. Attention: native SDPA is the safe choice; the Sage options are faster.

3. Write the shot

The Guided tab builds the prompt from fields: Style, Summary, one or more shots (shot 1 has no timestamp, later shots take MM:SS.mmm), dialogue lines (language, which subject speaks, separate, overlap or interrupt, delivery, and the exact words), Soundscape and Music (blank means none). Aim for 350–500 words. The assembled prompt is shown below the fields; Raw prompt lets you edit it directly.

4. Generate and keep takes

Production preflight lists anything that blocks the run and anything worth checking. Generate Ref2V makes a take. Each take keeps its exact setup and seed: Restore take setup brings it back, Send to timeline places it on V1 and A1, and Remove take deletes it. The cast, shots and takes are all saved in the project.
